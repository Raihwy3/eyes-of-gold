# CIA build

This is a standalone installed application, rather than a forwarder to the 3DSX.

Install the release’s `.cia` file with FBI and launch Eyes of Gold Launcher from HOME Menu. Keep the existing `/3ds/eyes-of-gold-native-game/` folder on the SD card. ROMs, settings, saves and converted assets use the same absolute paths as the 3DSX; there is no separate CIA data folder. An existing installation does not need its assets prepared again just because it uses CIA.

A fresh installation still needs a legally backed-up US retail ROM in that folder, named `GoldenEye.n64`, `GoldenEye.z64` or `GoldenEye.v64`.

The CIA startup updater checks for a newer release and can download its CIA to `/3ds/eyes-of-gold-native-game/launcher-update.cia`. Close the game and install that file with FBI. The 3DSX updater installs its own package separately. Both formats share `native-options.ini` and the save files.

## Building

Run `make cia` to build and validate the native engine, then package it. If the current native engine has already been built, `python3 native-engine/tools/build_cia.py` can package that build without repeating the full engine checks. It recompiles the CIA platform entry point and links a separate ELF; it does not overwrite the 3DSX release ZIP.

In addition to the normal toolchain, install Pillow, makerom and bannertool. Set `MAKEROM` and `BANNERTOOL` to their executable paths, put them on PATH, or place them in the ignored `local/cia-tools/` folder. Packaging does not download tools automatically.

The tested tools were:

- [makerom 0.19.0](https://github.com/3DSGuy/Project_CTR/releases/tag/makerom-v0.19.0), Ubuntu x86-64 ZIP SHA-256 `287b809dec064e0ad597e3d272c49ecb7eed41693d5ee6fef9d8a8aa24c2497e`.
- [bannertool 1.2.3](https://github.com/carstene1ns/3ds-bannertool/releases/tag/1.2.3), Linux tarball SHA-256 `748519d200519db18e9fd00c332ac32f5411e41230258291e89953a76c1f7155`.

Output is written to `local/releases/cia/`. The CIA ZIP uses the distinct name `eyes-of-gold-cia-VERSION.zip`, so the 3DSX updater will ignore it if both packages are attached to a release. The build packages the custom 3D eye/title model with generated silence. It includes makerom’s MIT-licensed Homebrew boot logo in ExeFS, with its license notice. It includes no Nintendo boot logo, game-data RomFS, ROM or extracted game files.

## Application settings and validation

The title ID is `000400000E064D00`. Keep it stable for future CIA updates. `native-engine/cia/launcher.rsf` defines SD access, the required system services and the existing worker-core access. It requests the 80 MiB application mode on Old 3DS and 124 MiB on New 3DS; these are memory limits rather than a performance guarantee. Old 3DS extended-memory mode can restart HOME Menu when leaving the application.

The package check compares every ELF load segment with the installed `.code` payload, checks ExeFS hashes, verifies the icon/banner, homebrew boot-logo digest and title ID, and confirms that game paths still point to the shared SD folder. The original ROM-data audit also runs on the CIA ELF. Reports are in `native-engine/build/cia/`.

These checks do not replace a console boot, gameplay and HOME Menu exit test.

The first CIA test omitted the boot logo. The package validator now rejects that build and requires the verified Homebrew logo; whether this resolves the launch error still needs console testing.

## Custom banner

The HOME Menu banner uses the project eye emblem on a transparent background, with “Eyes of Gold” in gold script beneath it. The artwork is `native-engine/cia/eye-transparent.png`; its generation prompt is recorded alongside it in `banner-artwork.txt`. The eye and lettering are extruded 3D geometry. No automatic skeletal rotation loop is included; HOME Menu supplies its microphone/motion response. Set `EOG_BANNER_FONT` to an installed script-font path if the default Z003 font is unavailable.

Regenerate the 3D model with `python3 native-engine/cia/make_banner.py --pycgfx /path/to/pycgfx`. This needs matplotlib, numpy, shapely, mapbox-earcut, gltflib and Pillow. The generated `native-engine/cia/banner.cgfx` is included so ordinary CIA builds do not need these extra tools. It is checked against HOME Menu’s 512 KiB model limit. The converter is MIT licensed; its notice is included with the packages.

The startup and updater use matching custom eye/title artwork, generated by `python3 native-engine/tools/launcher_art.py`. Its RGB565 header is committed so normal builds do not need a host font. Homebrew Launcher lists Raihwy3 as the author.

Use a makerom build with its version-macro collision corrected; the packager checks the installed title version and rejects mismatches. The fix for Project_CTR commit `d52c2b0e788c2d085763d7c5dcc4b2edd9ffb7d8` is included as `native-engine/cia/makerom-version.patch` (`git apply --unidiff-zero`).

CIA metadata includes the release revision starting with 0.9.7-r4. The installed version is 2420 (rather than the legacy 151 shared by earlier 0.9.7 revisions), while the title ID and SD directory remain unchanged. This gives each revision a distinct update version; it does not guarantee HOME Menu will immediately discard a previously cached icon.
