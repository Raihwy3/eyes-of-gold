# Build test

The exported source was cloned into a separate temporary directory and built with the installed devkitPro toolchain. No development build outputs or converted assets were copied into it. The build received only the pinned upstream checkout and a privately supplied US ROM.

Two old test paths still used filenames from an earlier converter. They were changed to the filenames generated by the current converter. Packaging also needed to create `local/releases/` before writing the ZIP. After those fixes, `make` completed successfully.

The completed build compiled all 217 engine units, passed the host conversion and renderer checks, linked the game and passed the strict ROM-data audit. The audit covered 1,477 ROM-backed definitions and reported no unresolved original initialized data. The generated 3DSX passed relocation validation, and the install ZIP passed its file and CRC checks.

The setup instructions now include the required Python package, `pyelftools`. The generated ZIP and full build log are kept under ignored `local/clean-build-test/`, outside the published source.

This checks that the source can produce an install package. It does not replace testing that package on a console. Network access was unavailable in the test environment, so both source repositories were cloned locally and the pinned upstream revision was checked with `tools/setup.py --check`. Downloading the upstream checkout from GitHub was not tested.
