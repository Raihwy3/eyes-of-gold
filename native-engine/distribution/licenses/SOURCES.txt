Dependency license sources

The linked game uses the inherited engine and PC port, Fast3D, libctru, Citro3D,
newlib (C/math/system support) and GCC's libgcc/libstdc++ runtime support.
Build-only tools are not shipped in this install archive; their original license
files remain in their source/tool distributions. No OpenGL/glad runtime is linked
in this 3DS build.
